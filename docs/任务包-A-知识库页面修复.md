# 任务包 A：知识库页面修复（紧急）

## 问题描述
知识库页面全白，显示错误：`Cannot GET /knowledge.html`

## 原因分析
- 路由配置可能缺失
- 静态资源路径可能错误
- 页面文件可能不存在

## 需要检查的地方
1. **路由配置** `routes/` 目录
   - 是否有知识库路由配置？
   - 路径是否正确？

2. **静态资源** `public/` 目录
   - 是否存在 `knowledge.html` 文件？
   - 如果不存在，需要创建

3. **Express 服务器配置** `server.js`
   - 静态资源中间件配置是否正确？
   - 路由顺序是否有问题？

## 修复步骤
- [ ] 找到错误的根本原因
- [ ] 修复路由或创建缺失的文件
- [ ] 本地测试：访问 http://localhost:3000/knowledge.html 应该能看到页面
- [ ] 确保没有影响其他页面

## 验收标准
1. 知识库页面能正常访问
2. 页面显示正常（不是全白）
3. 其他页面功能不受影响
4. 测试全部通过：`npm test`
