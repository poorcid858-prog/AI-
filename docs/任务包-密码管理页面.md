# 任务包 D：密码管理前端页面

> **状态**：⬜ 待认领
> **难度**：中等
> **预计时长**：30 分钟
> **使用 skill**：`superpowers:test-driven-development`

## 任务描述

为密码管理功能（`lib/password-mgmt.js` + `routes/password-mgmt.js`）创建前端管理页面，让 PM 可以在浏览器中修改访问口令和管理密码。

## 背景

密码管理 API 已完成（4 个端点），但缺少前端页面。PM 需要浏览器界面管理口令，不能直接调 API。

## 功能需求

### 页面：`public/password-mgmt.html`

#### 功能 1：查看口令状态
- 显示当前访问口令是否已设置
- 显示上次修改时间
- 显示口令长度

#### 功能 2：修改访问口令
- 输入当前管理员口令
- 输入新管理员口令
- 输入新访问口令
- 确认新访问口令
- 提交修改

#### 功能 3：重置为默认口令
- 输入管理员口令
- 一键重置为默认口令

#### 功能 4：安全口令生成工具
- 点击生成安全口令建议
- 显示建议口令（可复制）
- 刷新生成新的建议

## 实现方案

### 步骤 1：创建前端页面
- `public/password-mgmt.html`
- 表单 + 状态展示 + 交互
- 调用现有的 4 个 API 端点

### 步骤 2：集成到导航
- 在 `public/index.html` 或 `dashboard.html` 添加入口
- 或在 server.js 中配置静态路由

### 步骤 3：测试
- 前端交互测试（手动）
- 保证现有 379 个测试全部通过

## 涉及文件

- **新**：`public/password-mgmt.html` — 密码管理页面
- **改**：`public/index.html` 或 `dashboard.html` — 添加入口链接
- 不改：`lib/password-mgmt.js`、`routes/password-mgmt.js` — 已有 API

## 验收标准

- [ ] 页面可访问 `http://localhost:3000/password-mgmt.html`
- [ ] 显示当前口令状态
- [ ] 可以修改访问口令（需管理员口令）
- [ ] 可以重置为默认口令
- [ ] 能生成安全口令建议
- [ ] 失败时显示错误提示（管理员口令错误等）
- [ ] 成功时显示成功提示

## 注意事项

- 前端页面是供 PM 使用的，设计要直观
- 管理员口令和访问口令是两回事，UI 要清晰区分
- 安全考虑：不要在前端暴露口令明文超过必要时间
