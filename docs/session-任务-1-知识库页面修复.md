## 问题描述

用户访问知识库页面时，看到错误：`Cannot GET /knowledge.html`  
知识库页面应该显示知识库列表，但目前无法访问。

---

## 需要做什么

### 步骤 1：调查根本原因（30分钟）

找到为什么知识库页面无法访问。可能的原因：
- 路由配置缺失
- 静态文件缺失
- 路由顺序有问题
- 中间件配置有问题

**检查这些位置**：
- `server.js` - Express 路由和静态资源配置
- `routes/` - 所有路由文件
- `public/` - 是否有 `knowledge.html` 文件

**命令**：
```bash
# 在项目根目录执行
grep -r "knowledge" server.js routes/
ls -la public/knowledge*
```

### 步骤 2：修复问题（30分钟）

根据找到的原因修复：
- 如果文件缺失 → 创建 `public/knowledge.html`
- 如果路由缺失 → 在 `server.js` 或 routes 中添加路由
- 如果中间件问题 → 调整中间件顺序

### 步骤 3：本地测试（30分钟）

- [ ] 启动服务器：`npm start`
- [ ] 访问 http://localhost:3000/knowledge.html
- [ ] 验证页面能正常显示（不是全白，不是404）
- [ ] 检查其他页面是否还能访问
- [ ] 运行测试：`npm test`
