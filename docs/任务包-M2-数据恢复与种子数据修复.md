# 任务包 M2：数据恢复 + 种子数据修复

> 对应 PM 问题：**问题2（能力中心、审核中心不显示任何信息）**

---

## 1. 任务描述

修复能力中心、审核中心不显示数据的问题。核心原因：四层数据主文件为空、能力数据无审核状态、种子数据缺失。

## 2. 当前问题

### 2.1 文档审核列表为空
- `data/raw_documents.json` **主文件为空** `[]`
- 备份文件 `data/raw_documents.json.bak` 有数据（100+ 条），但未恢复
- 同样 `data/std_documents.json.bak` 有数据，主文件为空
- 导致审核中心文档审核列表无数据显示

### 2.2 能力审核列表为空
- `data/capabilities.json` 中的 4 条能力（skill_product, skill_test, skill_frontend, skill_cs）
- 所有能力的 `draft` 字段均为 `null`，`review` 字段不存在
- `getPendingReviewCapabilities()` 过滤 `c.review.status === 'pending_review'`，返回空

### 2.3 能力中心可能为空
- `store.js` 的缓存机制：首次读文件为空时缓存空数组，后续不再读文件
- 若服务启动时文件异常导致缓存空，能力中心永远显示空

## 3. 修改清单

### 3.1 恢复四层数据
- 从 `data/raw_documents.json.bak` 恢复 `data/raw_documents.json`
- 从 `data/std_documents.json.bak` 恢复 `data/std_documents.json`
- 需要确保 chunks.json 和 vectors.json 也初始化（当前可能不存在）
- 调用 `store.clearCache()` 清除缓存使新文件生效

### 3.2 为能力创建审核种子数据
- 修改 `data/capabilities.json`：为其中 1-2 条能力添加 `draft` 和 `review` 字段
- 使其出现在 `pending-review` 列表中
- 或者在 `lib/capability-engine.js` 的 `getDefaultCapabilities()` 中直接生成带草稿和审核状态的能力

### 3.3 修复 store 缓存防御
- 在 `lib/store.js` 的 `read()` 函数中，增加读取失败时自动重试逻辑
- 或在 `server.js` 启动时增加数据完整性自检（检查 `raw_documents.json` 是否为空，若为空尝试从 `.bak` 恢复）

### 3.4 前端空态优化
- `capability.html`：数据为空时展示友好提示（"暂无能力，点击新建能力开始"），避免白屏感
- `review.html`：文档审核/能力审核列表为空时展示友好提示和操作引导
