## 功能概述

AI 客服独立子系统，采用关键字匹配（而非向量检索），为客服提供标准话术回复。

## 架构：三层

### 核心算法层（`lib/service-engine.js`）
- `tokenize()` — 中文 unigram+bigram、英文按词分词
- `removeStopwords()` — 过滤常见虚词
- `normalize()` — 同义词映射到标准词
- `calculateIdf()` — 计算词权重
- `scoreMatches()` — 关键字打分排序
- `processQuestion()` — 端到端流程（6 个单元测试 ✅）

### API 路由层
- `routes/service-chat.js` — `POST /api/service-chat/send` 客户问题匹配
- `routes/service-admin.js` — 话术库管理（CRUD）+ 同义词管理（CRUD）

### 前端页面层
- `public/service-chat.html` — 客户对话窗口（实时匹配、加载动画、转人工提示）
- `public/service-admin.html` — 后台管理（话术库 Tab + 同义词表 Tab + 未命中池 Tab）
