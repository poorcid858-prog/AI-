# 任务包 G：管理后台配置功能

## PM 要求（来自问题6）
管理后台需支持以下配置：

### 6.1 密码配置
- 临时用户访问需要密码
- 可生成临时密码以及设置有效期
- 最长有效时间是 1 个小时
- **PM本人登录不用密码**（需设计识别机制，例如：本机IP/特定用户名等）

### 6.2 知识库切分方法配置
- 可按 token 数量切分
- 也可按文档几级副标题切分

### 6.3 AI聊天提问模板配置（关联任务包E）
- 最多配置10条
- 可分别为测试、产品、前端配置

### 6.4 分层级 Prompt 配置
- 可针对**全系统**、**各岗位**、**各业务线**配置分层级的 prompt

## 当前状态
- `lib/password-mgmt.js` 存在（可能与密码管理需求相关，但需确认是否支持临时密码+有效期）
- `config.js` 有 processing 配置（splitMode/fixedSize等）
- 需要确认上述配置项是否已实现

## 修复范围
- `lib/password-mgmt.js` — 确认/扩展临时密码功能
- `lib/document-processor.js` 或 `lib/knowledge-layers.js` — 切分方法配置
- 新建 `lib/config-center.js`（如不存在）或扩展 `lib/store.js` — 统一配置中心
- `routes/admin.js` — 配置管理API
- `public/admin.html` — 管理后台配置页

## 验收标准
1. 可生成临时密码，设置有效期（限制≤1小时）
2. PM可免密登录
3. 切分方法可配置（token/副标题）
4. 提问模板可配置（≤10条，按岗位）
5. 分层级Prompt可配置（全系统/岗位/业务线）
