# 任务包 B：系统管理员权限补全（紧急）

## 问题描述
系统管理员应该有全部权限，但目前还是没有审核权限。需要检查权限管理系统，补全管理员权限。

## 权限模型调查
首先需要理解当前系统的权限模型：

### 需要找到
1. **权限定义** - 系统中定义了哪些权限？
   - 查看权限
   - 编辑权限
   - 删除权限
   - 审核权限
   - 其他权限？

2. **角色定义** - 系统中定义了哪些角色？
   - 系统管理员
   - 内容管理员
   - 审核员
   - 普通用户
   - 其他角色？

3. **权限分配** - 每个角色有哪些权限？
   - 代码位置在哪里？
   - 数据库存储在哪里？

4. **权限检查** - 系统如何检查权限？
   - 中间件在哪里？
   - 检查点在哪里？

## 修复步骤
- [ ] 找到权限管理的代码位置（`lib/` 或 `routes/` 中）
- [ ] 调查当前系统管理员缺少哪些权限
- [ ] 给系统管理员补全所有权限（特别是审核权限）
- [ ] 检查所有受保护的接口，确保管理员都有访问权限
- [ ] 测试各个功能是否都能访问

## 检查清单
权限需要包括：
- [ ] 页面访问权限（所有页面）
- [ ] 文档上传权限
- [ ] 文档删除权限
- [ ] 审核权限（重点）
- [ ] 用户管理权限
- [ ] 系统配置权限
- [ ] 其他权限？

## 验收标准
1. 系统管理员可以访问所有页面
2. 系统管理员可以执行所有操作（特别是审核操作）
3. 其他用户的权限不受影响
4. 测试全部通过：`npm test`

## 工作量估计
- 调查权限模型：30分钟
- 补全权限：30分钟
- 测试：1小时
- **总计**：约2小时
