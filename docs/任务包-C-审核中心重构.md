# 任务包 C：审核中心重构

## 问题描述
审核中心页面太潦草，缺少基本的表格列表，不符合市面上产品的设计逻辑。

## PM 要求
- 审核中心应为**表格列表**，一行对应一个文件
- 操作栏可选择审核操作（通过/驳回）
- 能看到最近上传的文件的审核状态

## 当前问题
- `public/review.html` — 现有页面结构简陋，缺少表格
- `routes/admin.js` — 审核相关 API 需要确认

## 修复范围
- `public/review.html` — 重构为表格列表
- `public/css/` — 增加表格样式
- `routes/admin.js` — 审核 API（确认已有：listPending / review 等）
- `lib/qa-store.js` / `lib/documents.js` — 确认数据源

## 表格设计要求
- 列：文件名 | 上传时间 | 上传人 | 状态 | 操作
- 状态：待审核 / 已通过 / 已驳回 / 已发布
- 操作：通过 / 驳回（仅待审核状态显示）
- 支持分页（如文档多）

## 检查清单
- [ ] 审核列表 API 返回完整字段（文件名/时间/上传人/状态）
- [ ] 表格 UI 实现
- [ ] 通过/驳回操作可用，操作后状态更新
- [ ] 最近上传的文件优先显示，审核状态可见
- [ ] 测试全部通过：`npm test`

## 验收标准
1. 审核中心为清晰的表格列表
2. 每行对应一个文件，含完整信息
3. 操作栏可执行通过/驳回
4. 状态实时更新
5. 整体风格与系统其他页面一致
