# 前端 / UI 插件清单（已集成）

> 本清单是项目**前端插件唯一索引**。所有前端开发必须先查这里：已有能复用的，就复用，不要手写原生方案。
> 插件的静态文件已复制到 `public/js/vendor/`（JS）与 `public/css/vendor/`（CSS），**不用 CDN 直接引用本地即可，离线可用、上云一致**。

---

## 一、强制规则（契约 4 的执行细节）

1. **优先复用**：新建搜索框、表格、弹窗、图表、编辑器等场景，先看本清单有没有现成插件。
2. **本地化使用**：页面通过相对路径引用 `public/js/vendor/...`、`public/css/vendor/...`，不要外链 CDN。
3. **添加新插件三步**：
   - `npm install <包名>`（锁进 package.json）
   - 在 `scripts/vendor-copy.js` 里加一条 `{ from, to, j }` 记录
   - 执行 `npm run vendor` 复制到 public，然后在清单里登记“用途 + 版本 + 主题适配说明”
4. **主题适配**：本平台是 **Bootstrap 5.3 深色主题**（`public/css/custom-theme.css`）。部分插件（如图表、下拉）默认浅色，接入时按需要补一句深色覆盖 CSS。

## 四、引用示例

```html
<!-- HTML 模板页，按需引入。JS 建议放 </body> 前，CSS 放 <head> -->
<head>
  <link rel="stylesheet" href="/css/vendor/bootstrap-icons.css">   <!-- 图标字体 -->
  <link rel="stylesheet" href="/css/vendor/datatables.css">          <!-- 表格 -->
  <link rel="stylesheet" href="/css/vendor/sweetalert2.all.min.css"> <!-- 若用 sweetalert2-all 已含样式可省 -->
</head>
<body>
  <script src="/js/vendor/dataTables.mjs" type="module"></script>  <!-- DataTables 3 是 ESM -->
  <script src="/js/vendor/sweetalert2.all.min.js"></script>
  <script src="/js/vendor/lucide.min.js"></script>
</body>
```

> 图表的深色适配示例（ECharts）：
> ```js
> const chart = echarts.init(el);
> chart.setOption({ backgroundColor: 'transparent', textStyle: { color: currentThemeTextColor } , ...});
> ```

## 五、注意事项 / 已知限制

1. **DataTables@3 是 ESM**：用 `<script type="module">` 引入并通过 `import` 使用，或改用普通 script（若插件提供 UMD）。当前复制的是 `dataTables.mjs`。
   - 若页面需要普通 script 式用法，可另装 `datatables.net-dt`（提供 jQuery + UMD 版）。
2. **Bootstrap 已在本地**：页面原用 CDN 引用的 `bootstrap@5.3.3` 现已有本地副本 `js/vendor/bootstrap.bundle.min.js`，建议新页面直接引用本地。
3. **Select2 / Flatpickr / SweetAlert2 默认浅色**：在深色主题下导航 hover 等可能偏白，接入时在 `custom-theme.css` 补覆盖样式。
4. **Quill Snow 主题偏浅**：需补深色工具条/内容样式。
5. **字体图标**：`bootstrap-icons` 的 `fonts/` 已复制到 `css/vendor/fonts/`，CSS 内字体路径相对自身目录，无需改。
6. **js-beautify**：完整 UMD 版会同时挂 `beautify/js_beautify/css_beautify`，容量较大（约 228KB），仅在需要格式化功能的页面引入。
