# 需求 7：回答对比调试工具

> **对应需求文档**：`docs/需求文档.md` 第 10.3 节
> **状态**：⬜ 待实现
> **优先级**：高（需求文档标注"真实模式专属"）

## 需求背景

光有写权限不够。改完文档后靠记忆去比对上次的回答，这没法用。需要一个专门的对比工具，让管理员能直观看到改动前后的效果差异。

## 功能描述

### 功能 1：维护一组测试问题

- 内部助手：10 个典型需求（如"订单管理模块退款需求的 PRD"）
- AI 客服：10 个典型客户问题（含口语化说法）
- 管理员可以增删改测试问题

### 功能 2：生成快照 A

- 点击"跑一遍" → 生成快照 A
- 记录每个问题的：
  - 拆解结果（分词/停用词/同义词归一）
  - 召回片段（含相似度分数）
  - 最终 AI 回答
  - 客服命中率（客服模式）

### 功能 3：生成快照 B

- 管理员去改东西（改文档/调参数/改 Prompt/改同义词）
- 点击"再跑一遍" → 生成快照 B

### 功能 4：快照 A ↔ 快照 B 并排对比

- 哪些问题的召回片段变了
- 哪些回答内容变了
- 客服命中率 / 转人工率的变化
- 结论：变好、变坏、还是无影响

### 这个工具同时服务三件事

1. 需求 6（召回可观测）的「重新加工回归验证」
2. 需求 5（AI 能力中心）的「Prompt / Skill 改动试跑对比」
3. 需求 3（AI 客服子系统）的「同义词表效果验证」（命中率 62% → 87% 这类硬指标）

## 验收标准

- [ ] 测试问题列表可维护（增删改）
- [ ] 点击"跑一遍"生成快照 A
- [ ] 改动后点击"再跑一遍"生成快照 B
- [ ] 快照 A/B 并排对比，差异可视化
- [ ] 显示命中率、转人工率等量化指标变化
