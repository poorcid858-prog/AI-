# 企业 AI 辅助工具 · 部署说明

## 环境要求

| 项目 | 要求 | 验证 |
|------|------|------|
| Node.js | >= 18 | `node --version` |
| npm | 随 Node 附带 | `npm --version` |
| 内存 | 最低 256MB（推荐 1GB+） | - |
| 磁盘 | 200MB+（含 node_modules） | - |

## 部署方式一：裸机部署（推荐）

### 1. 安装依赖

```bash
cd /path/to/ai-assistant
npm install
```

### 2. 配置环境变量

```bash
cp .env.example .env
# 编辑 .env，按需修改端口、大模型等配置
# 默认 mock 模式无需 API Key 即可启动
```

### 3. 启动服务

```bash
# 直接启动
npm start

# 或用 pm2 进程守护（推荐）
npm install -g pm2
pm2 start server.js --name ai-assistant
pm2 save
```

### 4. 配置反向代理（可选）

生产环境建议用 nginx 反向代理，示例配置：

```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

### 5. 验证

```bash
curl http://localhost:3000/api/health
# 应返回 {"ok":true,"llmMode":"mock","readonlyMode":false,...}
```

## 部署方式二：Docker 部署（需先配置 Dockerfile）

> 本项目不内置 Dockerfile，如需要 Docker 部署请自行创建

```dockerfile
FROM node:20-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install --production
COPY . .
EXPOSE 3000
CMD ["node", "server.js"]
```

## 更新部署（已有项目在运行）

```bash
# 本地
git push origin master

# 云服务器
cd /opt/ai-assistant
git pull
pm2 restart ai-assistant
```

```bash

```

## 内置定时任务

服务默认在 23:00 自动生成日报告（基于内置持久化调度器，非系统 cron，需服务常驻）。

## 只读模式（对外演示）

```bash
# 启动时设置环境变量
READONLY_MODE=true npm start
```

开启后 guest 角色的所有写操作（创建、编辑、删除）被后端拦截，适合对外展示场景。

## 数据安全

- 运行时数据存储在 `data/` 目录（被 .gitignore 排除，不入库）
- 环境变量文件 `.env` 被 .gitignore 排除，不会提交到代码仓库
- 迁移服务器时需手动同步 `data/` 目录
