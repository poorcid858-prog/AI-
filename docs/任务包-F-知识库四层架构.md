# 任务包 F：知识库四层架构

## PM 要求（来自问题5）
知识库应有四层：
- **第一层**：原始文档（上传的 Word/PDF/PPT）
- **第二层**：标准化文档（经过清洗、去重、规整、打标签）
- **第三层**：Chunk（经过切分后的文档片段）
- **第四层**：向量化数据（经过向量化的文档）

**核心要求**：每一层都能通过ID找到对应的上一层文档是哪些（指向上层ID，实现溯源）
