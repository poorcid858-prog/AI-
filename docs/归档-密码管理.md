# 归档：密码管理

> **状态**：✅ 已完成（编码 + 测试通过）
> **对应需求文档**：`docs/需求文档.md` 第十章（单口令方案）

## 功能概述

单口令访问方案的管理功能。PM 通过管理员口令修改访问口令，管理访问权限。

## 实现内容

### 密码管理库（`lib/password-mgmt.js`）
- `verifyPassword()` — 口令验证
- `changePassword()` — 修改访问口令（需管理员口令保护）
- `getPasswordStatus()` — 获取口令状态
- `resetPassword()` — 重置为默认口令
- `generateSecurePassword()` — 生成安全口令建议

### API 端点
- `GET /api/password-mgmt/status` — 口令状态
- `POST /api/password-mgmt/change` — 修改口令
- `POST /api/password-mgmt/reset` — 重置口令
- `GET /api/password-mgmt/suggest` — 安全口令建议

### 测试
- `test/password-mgmt.test.js` — 11 个单元测试

## 设计特点
- **管理员口令与访问口令分离**，修改访问口令需要管理员口令
- 安全口令建议包含大小写字母、数字、特殊字符，长度 16+
- 所有修改操作都需要管理员口令保护

## 涉及文件
- `lib/password-mgmt.js` — 密码管理库
- `routes/password-mgmt.js` — 密码管理 API
- `test/password-mgmt.test.js` — 测试文件
