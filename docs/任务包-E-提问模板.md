# 任务包 E：提问模板

## PM 要求
AI助手聊天页新增一个**提问模板**功能，用户可以选择直接用提问模板提问，比如「生成一个PRD」。

## 需求细节
- 聊天页面提供预设模板列表
- 用户点击模板后，自动把模板内容填入输入框（或直接发送）
- 模板示例：「生成一个PRD」、「生成测试用例」、「生成前端组件」等

## 管理后台要求（关联任务包 G）
- 管理后台可配置提问模板，最多10条
- 可分别为测试、产品、前端配置（按岗位区分）

## 修复范围
- `public/workspace.html` — 聊天页增加模板选择区
- `public/chat.css` — 模板展示样式
- `lib/qa-store.js` 或新建 `lib/templates.js` — 模板数据存储
- `routes/chat.js` — 模板获取/使用接口

## 检查清单
- [ ] 聊天页展示预设模板
- [ ] 点击模板可填入输入框或直接发送
- [ ] 模板按岗位区分（产品/测试/前端）
- [ ] 管理后台可配置（关联任务包G）
- [ ] 测试全部通过：`npm test`

## 验收标准
1. 聊天页右上角或输入框上方有模板选择区
2. 点击「生成一个PRD」后，输入框自动填入完整模板内容
3. 模板内容可正常提交发送
4. 管理后台能增删改模板（如任务包G已实现）
