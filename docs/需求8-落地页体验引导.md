# 需求 8：落地页体验引导

> **对应需求文档**：`docs/需求文档.md` 第 10.4 节
> **状态**：⬜ 待实现
> **优先级**：中

## 需求背景

演示项目最大的失败是**访客点进来不知道该看什么就走了**。落地页必须给一条明确的体验路径，让新访客在 3 步内理解这个项目的核心价值。

## 功能描述

### 功能 1：三步体验引导

落地页展示三条指引步骤：

```
① 用「产品经理」身份，输入一个需求，生成一份 PRD
   → 看它引用了哪些企业文档

② 切换成「客服」身份，问同一个问题
   → 看答案怎么变（密级隔离生效了）

③ 切换成「知识管理员」，查看刚才那次回答的召回详情
   → 看它召回了哪些知识片段，以及怎么修
```

### 功能 2：每步有快捷入口

- 第 1 步：点击后直接跳转到工作台，角色设为产品经理
- 第 2 步：点击后跳转到工作台，角色设为客服
- 第 3 步：点击后跳转到 QA 审计页或召回分析页

### 功能 3：访客友好

- 全中文界面
- 简洁卡片式设计
- 移动端友好（响应式）

## 验收标准

- [ ] 落地页显示三步引导
- [ ] 每步有快捷入口，点击后跳转到对应功能页
- [ ] 界面简洁、全中文
