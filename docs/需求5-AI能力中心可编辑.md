# 需求 5：AI 能力中心「可编辑」

> **对应需求文档**：`docs/需求文档.md` 第 5.2 节
> **状态**：⬜ 待实现
> **优先级**：高

## 需求背景

Skill 和 Prompt 是"生成质量好不好"的直接原因，做成只读展示说服力不足。PM 确认升级为可真实配置，但必须配一套安全护栏。

## 功能描述

### 功能 1：编辑 → 存草稿（不生效）
- 管理员在 AI 能力中心页面编辑 Skill 或 Prompt
- 编辑后保存为草稿版，**不立即生效**
- 草稿版可以随时继续编辑

### 功能 2：试跑：拿真实需求跑一遍
- 草稿版可以点击"试跑"
- 选择一个真实的历史问题，运行一次 AI 生成
- 输出结果展示给管理员查看

### 功能 3：新旧版本输出并排对比
- 试跑结果与当前生效版本的结果并排展示
- 高亮差异部分
- 管理员判断是变好了还是变坏了

### 功能 4：发布生效 / 弃稿
- 满意 → 点击"发布"，草稿版替换为生效版本
- 不满意 → 点击"弃稿"，草稿版删除

### 功能 5：版本管理与回滚
- 保留最近 N 个生效版本
- 每个版本记录：谁改的、改了什么、何时生效
- 一键回滚到任意历史版本

### 功能 6：全程留痕
- 所有修改操作记录审计日志
- 可追溯：谁、什么时间、改了什么、生效了多久

## 验收标准

- [ ] 编辑 Skill/Prompt 后保存为草稿，不生效
- [ ] 草稿版可试跑，输出结果可查看
- [ ] 新旧版本并排对比，差异高亮
- [ ] 发布后草稿版替换生效版本
- [ ] 弃稿后草稿版删除，生效版本不变
- [ ] 版本列表可查看，可回滚
- [ ] 操作记录可追溯
