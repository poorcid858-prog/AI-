# 任务包 M1：侧边栏重设计 — 去掉 AI 工作台二级菜单

> 对应 PM 问题：**问题1（AI控制台不需要2级菜单）+ 问题4（菜单跳转错误）**

---

## 1. 任务描述

将左侧菜单「AI 工作台」的二级子菜单（产品助手/测试助手/前端助手/AI对话/历史记录）全部去掉，点击一级菜单直接进入聊天页面（workspace.html）。同时修正侧边栏 href 映射错误。

## 2. 当前问题

### 2.1 AI 工作台二级菜单无效
- `sidebar.js` 第14-25行：`workbench` 模块有 5 个子项
- 所有子项都指向 `workspace.html`（通过 `?role=` 参数切换角色）
- 但 `workspace.html` **不读取 `?role=` 参数**，角色切换功能无效
- "历史记录" href 指向 `/operations.html`（运营中心），是错误指向

### 2.2 菜单 href 映射错误
- `admin.html` 第71行调用 `renderSidebar('admin', 'doc')`，但 `doc` 是 `knowledge`（知识中心）模块的子项 → 导致用户点击"知识中心→文档管理"后，看到的是"系统管理"高亮
- `sidebar.js` 第33行：`chunk` 子项 href 指向 `/knowledge.html?tab=chunks`，但实际 Chunk 管理页是 `knowledge-quality.html`

## 3. 修改清单

### 3.1 修改 `public/js/sidebar.js`
- 删除 `workbench` 模块的 `children` 数组（第18-24行）
- 改为直接 `href: '/workspace.html'`
- 修改渲染逻辑（第113-132行）：当模块无 `children` 时，一级标题渲染为可点击链接（而非可展开的 div）
- 修正 `chunk` 子项 href：`/knowledge.html?tab=chunks` → `/knowledge-quality.html`
- 检查所有其他 href 映射是否正确

### 3.2 修改 `public/admin.html`
- 第71行：`App.renderSidebar('admin', 'doc')` → `App.renderSidebar('knowledge', 'doc')`

### 3.3 修改 `public/css/sidebar.css`（可选）
- 为无二级菜单的一级模块增加纯链接样式（无箭头、无展开）

### 3.4 更新测试 `test/sidebar.test.js`
- 更新第27行：确认 `workbench` 模块仍存在但无二级子菜单
- 新增测试：无子菜单模块渲染为链接
