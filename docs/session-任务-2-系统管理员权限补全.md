## 问题描述

系统管理员应该有全部权限（包括审核权限），但目前缺少部分权限。  
需要检查权限管理系统，补全管理员的所有权限。

---

## 需要做什么

### 步骤 1：理解权限模型（30分钟）

找到并理解系统的权限管理实现：

**查找这些内容**：
1. **权限定义** - 系统定义了哪些权限？
   ```bash
   grep -r "permission\|role\|privilege" lib/ routes/ --include="*.js" | head -20
   ```

2. **权限检查** - 权限是如何被检查的？
   - 中间件位置
   - 检查函数位置
   - 数据库中权限的存储方式

3. **当前管理员权限** - 管理员目前有哪些权限？
   - 查询数据库或配置文件
   - 列出所有现有权限

### 步骤 2：找出缺失的权限（30分钟）

系统应该有的权限（但可能缺少）：
- [ ] 查看权限（所有页面）
- [ ] 编辑权限
- [ ] 删除权限
- [ ] **审核权限** ← 重点
- [ ] 用户管理权限
- [ ] 系统配置权限

**对比**：
- 列出系统中定义的所有权限
- 列出管理员目前有的权限
- 找出差异

### 步骤 3：补全权限（30分钟）

根据找到的缺失权限进行修复：
- 修改数据库中管理员的权限记录
- 或修改权限配置文件
- 或修改权限检查逻辑

**关键**: 特别检查审核相关的权限。

### 步骤 4：测试验证（30分钟）

测试管理员是否有全部权限：
- [ ] 用管理员账号登录
- [ ] 访问每个页面（应该都能访问）
- [ ] 执行各个操作（应该都能执行）
- [ ] 特别测试：审核操作是否可用
- [ ] 运行测试：`npm test`

---

## 验收标准

✅ 管理员可以访问系统的所有页面  
✅ 管理员可以执行所有操作（特别是审核操作）  
✅ 其他用户的权限不受影响  
✅ `npm test` 测试全部通过

## 完成后

- [ ] 本地测试通过
- [ ] 提交代码：`git add -A && git commit -m "fix: 补全系统管理员权限"`
- [ ] 推送到 GitHub：`git push origin master`

## 重要提示

- ⚠️ 权限系统是敏感的，修改时要谨慎
- ⚠️ 不要给普通用户额外权限
- ⚠️ 修改后一定要充分测试
- ⚠️ 如果涉及数据库修改，备份现有数据

---

## 可能需要修改的位置

- `lib/auth.js` 或权限相关文件
- `routes/` 中受保护的接口
- 数据库中的用户权限表
- 权限配置文件（如果有）
