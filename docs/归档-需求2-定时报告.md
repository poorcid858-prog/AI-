## 功能概述

定时报告功能：会话结束后自动生成阶段报告，每天 23:00 生成日汇总报告。

## 实现内容

### 报告引擎（`lib/reports.js`）
- `generateSessionReport()` — 生成单个会话报告（计算时长、成功率）
- `generateDailyReport()` — 生成日汇总报告（聚合角色统计）
- `saveReport()` / `listReports()` / `getReport()` — 报告存储和查询
- `cronScheduleForDailyReport()` — 日报告 cron 表达式

### API 端点
- `GET /api/reports` — 报告列表
- `GET /api/reports/:sessionId` — 报告详情
- `POST /api/reports/generate/session` — 手动生成会话报告
- `POST /api/reports/generate/daily` — 手动生成日报告
- `GET /api/reports/cron/schedule` — 定时任务计划
