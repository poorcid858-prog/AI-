# 任务包 B：垃圾数据清理

> **状态**：⬜ 待认领
> **难度**：简单
> **预计时长**：10 分钟
> **需要决策**：PM 决定是否删除

## 任务描述

`data/documents.json` 中有 58 条垃圾数据（历史测试残留），需要 PM 决定是否删除。

## 背景

历史上项目测试往 `data/documents.json` 写入了 58 条垃圾记录（无标题、正文是占位文本）。这些数据：
- **不参与功能**（污染源已在测试阶段 9 切断）
- 但仍在 data/documents.json 中占用空间
- 只有 1 条真实数据（test.md），其余 57 条是垃圾

## 决策

⚠️ **需要 PM 决定：**

| 选项 | 效果 | 风险 |
|------|------|------|
| 删除 | 文件体积从 58 条变 1 条，干净 | 删除后不可恢复 |
| 保留 | 不影响功能，但文件有垃圾 | 无风险 |

## 执行方案

### 如果 PM 选择删除

1. 备份 `data/documents.json` 为 `data/documents.json.bak`
2. 只保留真实数据（doc_001/test.md），删除其余 57 条
3. 运行测试确认功能正常

### 执行步骤

```bash
# 1. 备份
cp data/documents.json data/documents.json.bak

# 2. 清理（手动删除 57 条垃圾行，只保留 doc_001）
# 或写脚本清理

# 3. 验证
npm test
```

## 本任务涉及文件

- `data/documents.json` — 唯一需要改的文件
- `data/documents.json.bak` — 备份文件
