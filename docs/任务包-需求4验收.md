# 任务包 A：需求 4 PM 手工验收

> **状态**：⬜ 待认领
> **难度**：简单
> **预计时长**：15 分钟
> **需要动作**：仅浏览器测试，不涉及代码修改

## 任务描述

PM 打开浏览器，手动验证需求 4（聊天式控制台）的 5 项功能是否正常。

## 验收前提

- 服务器已启动（`npm start`）
- 浏览器访问 `http://localhost:3000/workspace`
- 用 admin 身份登录

## 验收检查清单（5 项）

完成一项后标记 [✅] 或 [❌]

### 验收项 1：输入框高度
- [ ] 输入框显示高度明显增加
- [ ] 用户输入内容清晰可见
- [ ] 多行内容时输入框自动增高

### 验收项 2：岗位显示
- [ ] 右栏岗位由下拉改为静态展示
- [ ] 显示正确的岗位名称（如"产品经理"）
- [ ] 岗位不可更改（登录时确定）

### 验收项 3：常用问题点击逻辑
- [ ] 点击常用问题后，问题填入输入框
- [ ] 填入后不自动发送
- [ ] 用户按 Enter 或点发送按钮才发送

### 验收项 4：历史对话（中文）
- [ ] 历史对话列表仅显示中文摘要
- [ ] 无英文测试条目

### 验收项 5：常用问题（中文）
- [ ] 常用问题下拉仅显示中文问题
- [ ] 无英文问题

## 发现问题怎么办？

- 记录问题描述和截图
- 在进展.md 中记录
- 通知主 session

## 本任务涉及文件

无代码修改，仅浏览器测试。
