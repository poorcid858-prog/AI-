# 任务包 J：UI 优化

## PM 要求（来自问题9）
项目的UI实在太丑了，看看GitHub上排名靠前的UI插件，用一下优化我们的UI。

## 方向建议
引入一个成熟的前端UI框架来统一系统风格，推荐以下方案（需要调研后选择）：

### 方案一：Tailwind CSS + 组件库
- 优点：轻量、可定制、社区活跃
- 适合：当前项目的前端改造

### 方案二：Bootstrap 5
- 优点：成熟稳定、文档丰富、学习成本低
- 适合：快速出效果

### 方案三：Ant Design（通过CDN引入）
- 优点：组件丰富、表格/表单等功能强大
- 适合：管理后台类页面

## 修复范围
- `public/` — 全部页面样式统一
- `public/css/` — 引入UI框架，重构样式
- 优先改造：登录页、知识库页、聊天页、管理后台、审核中心

## 检查清单
- [ ] 选择并引入UI框架
- [ ] 所有页面样式统一
- [ ] 响应式基础
- [ ] 颜色风格统一，不再"简陋"
- [ ] 不影响现有功能
- [ ] 测试全部通过：`npm test`

## 验收标准
1. 整体UI风格统一，看起来专业
2. 表格、按钮、表单等组件美观
3. 页面布局合理，不再"简陋"
