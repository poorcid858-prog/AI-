# 企业 AI 辅助工具（含 AI 客服分支）

基于 RAG 知识库 + 提示词工程 + 工作流编排的企业内部 AI 辅助系统，为**产品、测试、前端、客服**四个岗位生成基础交付物。

## 解决什么问题

企业研发的痛点不是"AI 不会写文档"，而是**通用大模型不知道企业自己的业务规则**。同样一句"生成退款 PRD"，通用模型只能给出行业通用模板；本系统会先检索企业内部的订单系统文档、退款规则、历史需求，再基于真实业务规则生成。

## 快速开始

```bash
npm install
npm start
# 浏览器打开 http://localhost:3000
```

运行测试：

```bash
npm test
```

## 核心能力

| 能力 | 说明 |
|------|------|
| 文档安全分级与审核 | 上传 → 分级（public/internal/confidential/secret）→ 审核 → 入库 |
| RAG 知识库 | 段落切分、清洗去噪、文本归一化、去重 → 向量化 → 检索 → 重排序 |
| 提示词工程 | 角色设定、Few-shot 示例、任务指令、输出格式约束、边界约束（拒绝编造）、输出校验 |
| 业务线隔离 | 账号自动划分业务线，交易线人员检索不到会员线文档 |
| 工作流编排 | 意图识别 → 路由 → 加载 Skill → 权限过滤 → RAG 检索 → Prompt 组装 → 生成 → 质检 |
| 双向反馈 | 优秀问答对沉淀进实例库；优秀生成内容反哺 RAG 库（均需审核） |
| AI 客服分支 | 对外客户服务，仅检索 public 级知识，含拒答规则与转人工兜底 |

## 目录结构

```
lib/            核心引擎（预处理、向量检索、权限过滤、Prompt组装、工作流、质检、反馈）
lib/skills/     四个岗位的 Skill 定义
routes/         API 路由
public/         前端页面
mock-data/      模拟企业文档（电商交易线 + 会员线 + 客服知识库）
data/           运行时数据
test/           核心引擎测试
docs/           项目说明文档、部署说明
deploy/         数据重置脚本、部署配置
```

## 大模型接入

默认运行在**模拟模式**（本地按提示词规则组装返回），无需 API Key 即可跑通全流程。
接入真实大模型：在 `.env` 中配置 `LLM_MODE=real`、`LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`。
