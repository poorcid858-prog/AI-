# 云集商城退换货政策

亲爱的顾客，为了让您购物更放心，云集商城提供以下退换货服务。本政策适用于在云集商城购买的全部商品。

## 一、什么情况可以申请退换货

### 1. 七天无理由退货

自您签收商品之日起 **7 天内**，如果商品不影响二次销售，您可以申请无理由退货。

"不影响二次销售"是指：商品本体、包装盒、吊牌、说明书、赠品、发票齐全，商品没有使用过、没有洗涤过、没有人为损坏。

### 2. 质量问题退换货

如果商品存在以下情况，您可以申请退货、换货或补发：

- 收到的商品破损、开裂、变形
- 商品有明显的做工瑕疵、色差过大
- 商品功能不正常、无法开机、无法使用
- 收到的商品与订单不符（发错颜色、发错尺码、发错款式）
- 商品少发、漏发、缺少配件
- 商品已过保质期或临近保质期（食品类）

因质量问题退换货，您**不需要承担任何运费**，我们还会为您优先处理。

### 3. 家电大件延长服务

家用电器、3C 数码类商品，无理由退货时效延长至签收后 **15 天**。

### 4. 会员专属延长服务

如果您是云集商城的金卡或钻石会员，售后申请时效会更长：

| 您的会员等级 | 无理由退货时效 |
|---|---|
| 普通会员 | 签收后 7 天 |
| 银卡会员 | 签收后 7 天 |
| 金卡会员 | 签收后 15 天 |
| 钻石会员 | 签收后 30 天 |

## 二、什么情况不能退换货

很抱歉，以下商品因商品特性或卫生安全原因，签收后不支持无理由退换货（存在质量问题仍可申请）：

| 不支持退换的商品 | 原因说明 |
|---|---|
| 个人定制商品 | 刻字、印制姓名、按您的尺寸定做的商品，无法二次销售 |
| 生鲜、冷冻食品 | 水果、蔬菜、肉类、海鲜、冰淇淋等易腐商品 |
| 贴身衣物 | 内衣、内裤、袜子、泳装、塑身衣等直接接触皮肤的商品 |
| 已拆封的美妆个护 | 化妆品、面膜、口红、隐形眼镜等拆封后无法保证卫生 |
| 已激活的虚拟商品 | 充值卡、话费、视频会员卡、电子券，一经充值或核销即不可退 |
| 已拆封的音像与图书 | CD、DVD、软件、已拆塑封的图书 |
| 医疗器械与药品 | 按国家规定不支持退换 |
| 鲜花、蛋糕等定时配送商品 | 配送后无法二次销售 |

另外，以下情况我们也无法为您办理退货：

- 商品已经使用过，有明显使用痕迹、划痕、污渍、异味
- 商品吊牌被剪掉，或包装盒、说明书、赠品缺失
- 退回的商品与您购买的商品不一致
- 超过了退换货申请时效
- 商品的损坏是由于您使用不当、保管不当、擅自拆修造成的

## 三、怎么申请退换货

### 手机 App / 小程序申请（推荐）

1. 打开云集商城 App，进入「我的」→「我的订单」
2. 找到需要退换的订单，点击「申请退换货」
3. 选择退换货类型：仅退款 / 退货退款 / 换货
4. 选择退换原因，如果是质量问题，请上传商品照片（建议 3 张以上，清晰拍出问题部位）
5. 填写退款金额（系统会自动为您计算），提交申请
6. 等待审核，审核结果会通过 App 消息和短信通知您

### 网页端申请

登录云集商城官网 → 「我的订单」→ 找到订单 → 「申请售后」，后续步骤同 App。

### 联系客服申请

如果 App 上找不到售后入口，或者您的情况比较特殊，可以联系我们的在线客服（App 内「我的」→「联系客服」），或拨打客服热线 **400-800-1668**（每天 8:00 - 22:00）。

### 退货怎么寄回

1. 审核通过后，我们会在 App 上告知您退货地址
2. 请把商品和所有配件、吊牌、赠品一起打包，建议保留外包装
3. 寄出后，在 App 上填写您的快递单号，这一步很重要，否则我们无法及时收到您的退货
4. 请在审核通过后 **7 天内**寄出，超过 7 天未寄出，退款申请会自动关闭（您可以重新申请）

温馨提示：请不要使用到付方式寄回，到付件我们无法签收。

## 四、多久能收到退款

审核通过并且我们收到退货后，退款会立即为您办理。到账时间取决于您当时的付款方式：

| 您的付款方式 | 预计到账时间 |
|---|---|
| 云集账户余额 | 实时到账 |
| 微信支付 | 1 - 3 个工作日 |
| 支付宝 | 1 - 2 个工作日 |
| 储蓄卡 | 3 - 7 个工作日 |
| 信用卡 | 3 - 15 个工作日（具体看银行入账速度） |

退款会**原路退回**到您当时付款的账户，我们无法退到其他账户，也无法提现。

如果超过上述时间还没有收到退款，请您先查一下付款账户的账单明细，如果确实没有收到，请联系客服，我们会为您加急核实。

## 五、运费谁承担

| 退换货情形 | 商品运费（您下单时付的） | 退回商品的运费 |
|---|---|---|
| 商品还没发货就取消/退款 | 全额退给您 | 无需寄回 |
| 商品质量问题、发错货、少发漏发 | 全额退给您 | 我们承担（凭快递单据报销，最高 20 元） |
| 七天无理由退货，退了订单里全部商品 | 全额退给您 | 您承担 |
| 七天无理由退货，只退了部分商品 | 不退还 | 您承担 |
| 换货 | 不涉及 | 您寄出的运费自己承担，我们寄给您的免运费 |

**运费险**：如果您下单时购买了运费险，退货运费由保险公司赔付，赔付金额会在退货完成后直接打到您的付款账户。

**会员福利**：银卡及以上会员每年有免费退货运费的次数，退货时会自动为您抵扣，具体次数可以在「我的」→「会员中心」查看。

## 六、优惠券和积分怎么处理

我们知道您很关心这个，所以专门说明一下：

**如果您退掉了订单里的全部商品：**
- 使用的满减券、折扣券，只要还没到期，会原样退回到您的账户，可以继续使用
- 活动赠券、新人专享券这类券不退回
- 抵扣的积分会退回到您的账户，有效期不变
- 下单时获得的积分会被扣回

**如果您只退掉了订单里的部分商品：**
- 优惠券不退回（因为优惠已经分摊到了您保留的商品上）
- 退款金额是按这件商品实际付的钱来算的（也就是分摊优惠后的金额）
- 抵扣的积分会按比例退回一部分

举个例子：您买了 A 商品 200 元、B 商品 100 元，用了满 300 减 50 的券，实付 250 元。如果只退 A 商品，会退给您 166.67 元（A 商品分摊优惠后的实付金额），优惠券不退回。

## 七、换货说明

- 换货只能换同一款商品的不同规格（比如换个尺码、换个颜色），不能换成其他商品
- 同一件商品**只能申请换货 1 次**，换货后如果还有问题，只能申请退货退款
- 换货不涉及退款，如果新规格价格不同，我们会与您协商补差价或退差价
- 换货商品我们会在收到您的退货并检查合格后 48 小时内寄出

## 十一、售后小贴士

为了让您的售后更顺利，这几点小建议请您留意：

1. **收货时先验货**：外包装明显破损建议当场拒收，或者当着快递员的面开箱检查。
2. **发现问题尽早申请**：越早申请，我们越容易帮您向快递或商家核实责任，处理也更快。
3. **拍照要拍全**：拍质量问题时，建议拍 3 张以上：商品整体、问题部位特写、外包装与快递面单。有视频更好。
4. **别忘了填快递单号**：退货寄出后一定要在 App 上填写快递单号，这一步很关键，不填我们收不到货也没法退款。
5. **保留吊牌和包装**：吊牌剪了、包装扔了，无理由退货可能就办不了了，建议确认要留下再拆。
6. **别用到付寄回**：到付件我们无法签收，会被退回给您，反而耽误时间。
7. **一件商品换货只有 1 次机会**：所以选规格的时候尽量确认清楚，实在不合适可以直接退货重买。
8. **有疑问先问客服**：不确定能不能退、怎么退，直接问在线客服，我们会告诉您最合适的方案。

## 十二、审核不通过怎么办

如果您的退换货申请被拒绝，我们会告知您具体原因。如果您认为处理有误，可以：

1. 在 App 上对该售后单点击「申请客服介入」，我们的售后专员会重新核实
2. 每个售后单可以申诉 **1 次**，申诉会由售后主管处理
3. 如果涉及商品质量争议，您可以提供第三方质检报告，我们会按报告结论处理
4. 也可以直接联系在线客服或拨打 400-800-1668，我们会认真核实每一个申诉

常见的被拒原因和应对办法：

| 拒绝原因 | 您可以怎么做 |
|---|---|
| 超过退换货时效 | 如果是因为出差、住院等原因延误，提供说明后可以申诉 |
| 商品缺少吊牌或包装 | 如果吊牌还在，一起补寄给我们；确实丢失可申诉说明情况 |
| 商品有使用痕迹 | 如果是开箱查验造成的，可以提供开箱视频申诉 |
| 商品类目不支持退货 | 定制、生鲜、贴身衣物等确实无法办理，但质量问题仍可申请 |
| 退回商品与订单不一致 | 请核对是否寄错了包裹，联系客服我们帮您查 |
| 物流显示已本人签收 | 如果确实没收到，提供说明后我们会向快递发起查件 |

## 十三、我们的承诺

- 未发货订单申请退款，小额订单最快 **1 分钟内**自动审核通过
- 商家收到您的退货申请后，**24 小时内**必须处理，超时系统会自动同意退款
- 所有售后申请，我们承诺 **48 小时内**给您明确答复
- 质量问题的售后，运费我们全包，不让您承担一分钱
- 如果因为我们的原因造成您的损失，我们会主动补偿，不需要您反复争取
